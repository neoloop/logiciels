# logiciels

## EquipmentRequestApp

App iOS pour valider les demandes de matériel (ordinateur, téléphone, clé
USB...) soumises par les employés via un formulaire externe qui alimente un
tableau Excel sur OneDrive/SharePoint : liste des demandes en attente,
validation ou refus, génération d'un PDF à faire signer et envoi par mail.
Voir [EquipmentRequestApp/README.md](EquipmentRequestApp/README.md) pour
l'installation et la configuration.
