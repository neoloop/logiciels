# logiciels

## EquipmentRequestApp

App iOS pour saisir, valider et envoyer les demandes de matériel (ordinateur,
téléphone, clé USB...) : écriture automatique dans un tableau Excel
OneDrive/SharePoint et génération d'un PDF à faire signer, envoyé par mail.
Voir [EquipmentRequestApp/README.md](EquipmentRequestApp/README.md) pour
l'installation et la configuration.
