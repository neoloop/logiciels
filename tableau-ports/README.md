# tableau-ports

🇫🇷 Page HTML unique (sans dépendance) qui teste si vos services web internes répondent : tableau service / hôte / port / chemin, pastille en ligne / hors ligne, temps de réponse, auto-rafraîchissement optionnel. La liste est modifiable dans la page et mémorisée dans le navigateur.

**Utilisation** : ouvrir `index.html` (double-clic) depuis un poste qui voit vos serveurs. Adapter l'hôte par défaut et les ports dans la page. Depuis une page en https, le navigateur bloque les tests http.

🇬🇧 Single-file, dependency-free HTML page that checks whether your internal web services are up: service / host / port / path table, online / offline badge, response time, optional auto-refresh. The list is editable in the page and saved in the browser.

**Usage**: open `index.html` (double-click) from a machine that can reach your servers, then adjust the default host and ports. From an https page, the browser blocks http checks.
